# Amey Jeurkar — Portfolio

A personal portfolio built with Next.js and the App Router.

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Production

```bash
npm run build
npm start
```

The site uses Next.js metadata and server-rendered page content. Update the
profile, experience, skills, and project details in `app/page.js`.

The site defaults to a warm light theme on every visit. Use the control in the
top navigation to switch to the dark slate-and-green theme for the current
visit.
